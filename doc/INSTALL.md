# economic-indicator-overlay

Display multiple time zones as always-on-top desktop clocks.


## Install from PYPI

The homepage in pipy is https://pypi.org/project/economic-indicator-overlay/

```bash
pip install --upgrade economic-indicator-overlay
```

Using:

```bash
economic-indicator-overlay
```

## Install from source
Installing `economic-indicator-overlay` program

```bash
git clone https://github.com/trucomanx-desktop/EconomicIndicatorOverlay.git
cd EconomicIndicatorOverlay
pip install -r requirements.txt
cd src
python3 setup.py sdist
pip install dist/economic_indicator_overlay-*.tar.gz
```
Using:

```bash
economic-indicator-overlay
```

## Uninstall

```bash
pip uninstall economic_indicator_overlay
```
